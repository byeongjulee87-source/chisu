# 치수경제성 에이전트

하천기본계획 치수경제성 분석을 브라우저에서 한 번에 하는 도구입니다.
개수 전 측점별 홍수위와 수치지도를 올리면 하도버퍼링으로 침수심도를 만들고,
K-FRM(또는 다차원법) 피해액 → 연평균편익 → B/C·NPV·IRR → AHP 투자우선순위 → 치수경제성 보고서(hwpx)·결과 엑셀까지 만듭니다.

**사용:** https://byeongjulee87-source.github.io/chisu/ (GitHub Pages)  
계산은 모두 사용자의 브라우저 안에서 하며, 올린 파일은 어디로도 전송되지 않습니다.

## 넣는 자료

| 자료 | 형식 | 비고 |
|---|---|---|
| 입력 엑셀 | xlsx | 지구(1.1 하천개수계획 현황 그대로) · 단가(공사비 자동 산정) · 읍면동(선택) · 홍수위(선택). 화면의 [입력양식 내려받기] |
| 측선 + 개수 전 홍수위 | SHP(zip) 또는 DXF | SHP에 빈도별 홍수위 필드가 있으면 엑셀 홍수위 시트 생략 |
| 수치지도 | DXF | 등고선(F00171xx) · 표고점(F00272xx) |
| 지구계 | SHP(zip) 또는 DXF | DXF는 닫힌 선 + '…지구' 문자 |
| 환경부 토지피복도 | SHP(zip) | 한 번 넣으면 그 브라우저가 기억. K-FRM은 없어도 됨 |
| K-FRM 인벤토리(권장) | SHP(zip) | 건물(K-CDMS 또는 도로명주소 전자지도 건물) · 집계구 인구·차량 · 농경지 |
| 통계연보(선택) | xlsx · csv | KOSIS 읍면동별 표 → 읍면동 시트 빈칸 자동 채움 |
| 횡단면도(선택) | DXF | 원지형·계획지형 레이어 → 측점별 공종 수량(평균단면법) × 화면에서 넣은 공종 단가 → 공사비 |

## 피해액 산정법

- **K-FRM** (기본): 「하천기본계획 수립지침(2025)」 붙임 8, K-FRM 기술보고서(2023) · K-CDMS 원단위(2020)를 가격기준년도로 물가 환산.
  건물 31용도 손상함수·CSVR·출입구높이, 차량 3유형, 인명·이재민(PAR), 농작물 10종·농경지, 공공시설 0.865.
- **다차원법**: 「치수사업 경제성분석 방법 연구(2004)」.

## 소스 구조 (`src/`)

| 파일 | 내용 |
|---|---|
| `app.html` | 화면(파일 분류·입력 읽기·실행·결과·내려받기) |
| `gisr.js` | 하도버퍼링: 측선 홍수위 보간 × 수치지도 지형 → 침수심 격자, 구획 집계 |
| `kfrm.js` | K-FRM 매개변수와 피해 계산 |
| `econ.js` | 다차원법 피해액, 연평균편익, 현금흐름·B/C·NPV·IRR |
| `report.js` | 보고서 양식(hwpx) 표·문장 채우기, AHP |
| `stats.js` | 통계연보(KOSIS 표) 읽기 |
| `qe.js` | 횡단면도 → 측점별 공종 수량(@물량산출 엔진) |
| `crs.js` · `io.js` · `gis.js` | 좌표계 변환, SHP·DXF 읽기, 침수심 SHP 중첩 |
| `sample.json` | 계산 기준표(물가지수, 원단위 등) |
| `template.hwpx` | 보고서 양식 |
| `build.py` | 위 파일을 한 장짜리 `index.html`로 묶음 |

## 고친 뒤 다시 만들기

```
python src/build.py public
```

`index.html`이 새로 만들어집니다. 저장소에 올리면 1~2분 뒤 같은 주소에 반영됩니다.
